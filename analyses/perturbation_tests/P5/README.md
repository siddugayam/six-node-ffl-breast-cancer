# P5

## Scripts in this folder

| Script | What it does |
|---|---|
| `p5_atlas.py` | P5: mature miR-29a/b/c-3p and miR-101-3p in purified cell types, fibroblasts against mammary epithelial cells, in two atlases (SETTINGS.md, P5). |
| `p5_fetch.py` | P5: fetch the FANTOM5 miRNA atlas tables (de Rie et al. 2017; the atlas viewer's human data package). |
| `p5_microRNAome_export.R` | P5: export from the Bioconductor microRNAome package (McCall et al. 2017) the counts of the four miRNAs and each sample's total miRNA count (column sum over all miRNAs), with CellType and Class, to the 27d cache. |
