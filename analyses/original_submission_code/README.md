# Code and networks of the original submission

The six network files (`SIF_files/`: three-node miRNA-, TF- and composite-FFL networks and the four-, five- and six-node
exemplar circuits), their Cytoscape node tables (`node_attributes/`: the type of each node, with NetworkAnalyzer
statistics) and the R scripts of the original submission, released under the MIT licence (`LICENSE`).
`scripts/01_network_assembly/02_build_canonical_network.py` builds the network in `data/network/` from the network files
and node tables. `analyses/six_node_followups/Q5/` compares the six networks with the revised network.
