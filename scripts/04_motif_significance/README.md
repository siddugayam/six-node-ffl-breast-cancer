# Motif significance (Results 3.2)

`08_motif_significance.py` / `30_motif_significance.py` and `v2_null.c` + `v2_analyse_null.py`: three-node FFL counts in
the observed network against randomised networks under three null models. `08c_reciprocity_audit.py`: reciprocal TF↔miRNA pairs in the network and in the source databases;
`08_motif_node_sets.py`: the node sets of each FFL class; `10_*`, `11_*`: class comparison and specificity. The
analysed-network re-run is `analyses/census_and_motif_nulls/nulls/`.
