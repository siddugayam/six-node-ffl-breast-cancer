# Expression validation (Results 3.4)

| Folder | What it holds |
|---|---|
| `tcga_differential_expression/` | TCGA-BRCA preparation and tumour-versus-normal differential expression |
| `edge_correlations/` | Edge sign concordance against matched nulls, named axes, CAF-adjusted correlations |
| `external_cohorts/` | GEO, MET500 and other cohorts (`N*` build and analyse the cohorts) |
| `protein_cptac_and_rppa/` | CPTAC protein and RPPA validation |
| `subtypes_and_pan_cancer/` | PAM50 subtypes and pan-cancer generalisation |

These steps need TCGA and CPTAC patient-level data, which are not redistributed; their outputs are in `results/`.
